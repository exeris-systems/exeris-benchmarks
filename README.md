# Exeris Benchmarks

This repository contains reproducible benchmark suites for Exeris runtime repositories.

## Goals
- validate performance claims with reproducible methodology
- compare pure mode, compatibility mode, and implementation variants
- track regressions over time
- separate benchmark harnesses from product repositories

## Benchmark Families
- JMH microbenchmarks
- runtime HTTP load benchmarks
- compatibility-cost benchmarks
- cross-repo scenario benchmarks

## Target Repositories
- exeris-kernel
- exeris-kernel-enterprise
- exeris-spring-runtime
- future: sdk, studio, integrations

## Principles
- methodology before claims
- environment captured for every run
- no apples-to-oranges comparisons without explicit labeling
- pure mode and compatibility mode reported separately
- community and enterprise reported separately
