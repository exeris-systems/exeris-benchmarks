# results/

This directory stores benchmark run outputs.

## Structure

```
results/
├── raw/          # Direct tool output — wrk .txt, JMH .json, k6 .json
├── normalized/   # Result files normalized to benchmark-result.schema.json
├── summaries/    # Markdown reports generated by scripts/publish-report.sh
└── history/      # Archived named results: <tier>/<protocol>/<date>-<sha>.json
    ├── community/
    │   ├── h1/
    │   └── h2/
    ├── enterprise/
    │   ├── h1/
    │   ├── h2/
    │   └── h3/
    └── spring-runtime/
        ├── pure/
        └── compat/
```

## What goes here

- `raw/` — unmodified output from wrk, h2load, k6, JMH. Committed for traceability.
- `normalized/` — machine-readable files conforming to `schemas/benchmark-result.schema.json`.
- `summaries/` — human-readable Markdown summaries.
- `history/` — archived per-run results for long-term trend tracking.
- `summaries/protocol-matrix.md` — within-tier and cross-tier protocol report.

Generate protocol matrix report:

```bash
./scripts/report-protocol-matrix.sh results/normalized > results/summaries/protocol-matrix.md
```

## gitignore note

Raw files can be large. If raw/ becomes too large, consider adding large files to
`.gitignore` and archiving them externally, keeping only `normalized/` and `history/`
in git.
